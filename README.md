# Empowering Unemployed Youth: Development and Design of a Location-Based Mobile application for Community-based short-term Work (TaskSurf) 

TaskSurf is a C2C mobile freelance marketplace application designed to connect unemployed youth in South Africa with local task providers. Whether it is gardening, tech help, cleaning, or deliveries, TaskSurf provides a secure, location-based platform to post tasks, apply for work, and build a verified professional reputation.

## Key Features
- **Dual Roles:** Users can seamlessly switch between posting tasks (Provider) and applying for tasks (Worker).
- **Live Location Filtering:** Built-in GPS and custom radius filtering to find tasks or workers nearby.
- **Secure Verification:** Profile verification system to ensure trust and safety within the community.
- **Real-Time Applications:** Live applicant tracking with built-in status updates (Pending, Accepted, Rejected).
- **Reputation System:** 5-star rating and review system to help workers build their portfolios.
- **In-App Messaging:** Secure communication between task providers and workers.

## Tech Stack
- **Frontend:** Flutter (Dart)
- **Backend:** Firebase (Firestore, Authentication)
- **Location Services:** Geolocator & Geocoding
- **Version Control:** Git & GitHub
